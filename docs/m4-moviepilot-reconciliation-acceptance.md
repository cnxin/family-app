# M4 MoviePilot 后台对账验收

## 范围

- API 启动后自动对账 MoviePilot 请求，默认首次延迟 10 秒，之后每 60 秒运行。
- 待订阅和下载中的请求持续跟踪；最近 6 小时内完成或失败的请求继续复核。
- 对账覆盖活动订阅、活动下载、下载历史和整理历史，不依赖 Webhook 一定送达。
- 同一进程中的对账任务不重入，单条连接失败不阻断其他家庭请求。

## 状态规则

- MoviePilot 稳定订阅编号持久化；下载、整理等临时阶段编号不写入数据库。
- 进行中的请求在 MoviePilot 完全找不到记录时转为失败。
- 已完成或失败的请求在复核窗口内可以纠正，例如部分硬链接失败或重新整理成功。
- 已取消请求保持不变；旧请求存在新的进行中请求时不抢占状态。
- 只有状态真实进入完成或失败时才生成系统活动和申请人通知，进度变化不重复通知。
- 外部编号、状态说明、通知正文和活动摘要写入前按数据库字段长度截断。

## 配置

- `MOVIEPILOT_RECONCILE_ENABLED`：是否启用，默认 `true`。
- `MOVIEPILOT_RECONCILE_INTERVAL_MS`：轮询间隔，默认 `60000`。
- `MOVIEPILOT_RECONCILE_INITIAL_DELAY_MS`：首次执行延迟，默认 `10000`。
- `MOVIEPILOT_RECONCILE_FINAL_GRACE_MS`：终态复核窗口，默认 `21600000`（6 小时）。

测试环境显式关闭后台定时器，并通过纯状态契约覆盖记录消失、下载推进、失败后恢复、临时编号和长度限制；真实 NAS 验收同时确认正常完成请求与部分整理失败请求可以被区分。
