# M3-B 家庭任务与通用通知验收

> 验收日期：2026-07-29
> 状态：通过，任务实例与站内通知契约冻结

## 验收结论

M3-B 已形成家庭任务闭环。成员可以在移动与桌面 Web 中安排一次性或周期任务，按日期查看、认领、改派、完成、跳过、恢复和停用；首页展示今日任务，统一日历按来源聚合任务，通知中心汇总任务指派、任务完成和菜单划掉提醒。

## 数据约定

1. `household_tasks` 保存任务模板与周期规则，不保存日历副本。
2. `household_task_instances` 只保存发生过状态变化或改派的日期实例；普通待办按查询范围动态展开，避免为长期周期任务预写无限记录。
3. 周期支持一次性、每日、每周和每月，可设置 1 到 365 的重复间隔及结束日期。每月任务沿用开始日，缺少该日期的月份不生成实例。
4. 修改周期规则时只清理尚未处理的实例；已完成或已跳过的历史实例保留。停用任务后不再生成新的任务或日历条目。
5. `notifications` 保存面向单个成员的站内通知。列表必须同时按 `householdId` 与 `recipientId` 过滤，跨家庭或非接收人的已读操作按不存在处理。
6. 菜单划掉提醒继续保留旧 `menu_events` 记录；新旧通知接口任一侧标记已读，另一侧同步更新，旧客户端无需立即迁移。
7. 统一日历只在读取时调用任务模块并返回 `module=task`，来源权威数据仍在任务表。

## 权限约定

- 所有正式家庭成员都可创建任务并选择本家庭负责人。
- 创建者或 `owner/admin` 可编辑、停用和改派任务。
- 负责人可更新分配给自己的实例；未指派任务可由任一家庭成员认领或直接完成。
- 非负责人不能完成他人的任务；跨家庭任务、实例和通知返回 `404`。

## 接口契约

| 接口 | 作用 |
| --- | --- |
| `GET /tasks?start=YYYY-MM-DD&end=YYYY-MM-DD` | 展开指定范围内的任务实例，单次最多 371 天 |
| `POST /tasks` | 创建一次性或周期任务 |
| `PATCH /tasks/:id` | 创建者或家庭管理员编辑任务模板 |
| `DELETE /tasks/:id` | 软停用任务，保留历史数据 |
| `PATCH /tasks/:id/instances/:date` | 认领、改派、完成、跳过或恢复指定日期实例 |
| `GET /notifications` | 读取当前成员的未读通知，可通过 `includeRead=true` 包含最近已读通知 |
| `PATCH /notifications/:id/read` | 把当前成员的一条通知标记已读 |
| `PATCH /notifications/read-all` | 把当前成员的全部通知标记已读 |

## 后续边界

- M3-D 已为任务的明确发生日接入可配置定时提醒；M6-A6 后续增加了可选 Webhook/ntfy 外部投递，任务仍复用同一站内通知、成员偏好和投递历史，不直接绑定特定消息平台。
- 当前任务不包含检查清单、附件、完成审批、积分或多人参与者；这些能力应由真实使用场景驱动，不塞入任务基础表。
- 通用投票已由 M3-C 独立落地，复用家庭、成员、权限与通知边界，不把选票或结果复制进任务表。
