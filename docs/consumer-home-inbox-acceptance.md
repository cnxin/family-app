# 普通成员今日工作台与家庭收件箱验收

> 验收日期：2026-08-05
> 范围：普通成员移动首页、家庭收件箱、全局快捷新增和管理端界面隔离

## 验收结论

普通成员首页已从模块导航页调整为事件与行动优先的“今日家庭工作台”。管理账号在桌面端继续使用原有高密度工作台、通知渠道和投递运维界面，不因本批移动端调整降低操作密度。

本批不新增数据库表或迁移。任务、投票、提醒、通知和家庭活动仍由各自模块保存，首页与收件箱只读取并组合这些权威状态。

## 今日家庭工作台

- “需要我处理”展示今天可由当前成员完成或认领的任务、尚未参与的开放投票和当天购物清单。
- 首页默认只展开今日摘要、最多 3 项“需要我处理”和问小管家、家庭观影、家庭投票、采购与库存 4 个常用入口。
- “更多家庭内容”使用不小于 44px 的点击披露控件；展开后显示接下来、等待家人、家庭动态、本周概览、家庭回忆和其他功能。
- “接下来”展示当天菜单、家庭任务和近期提醒；“等待家人”只在确有协作事项时出现，不再渲染无内容的大卡片。
- “家里刚刚完成”读取不可变家庭活动记录，并保留到来源模块的深链；无动态时不占用首页空间。
- 普通成员首页与管理端首页继续通过成员角色分流，`owner/admin` 的桌面工作台保持不变。

## 家庭收件箱

- “需要处理”来自实时任务与投票状态，不以通知已读状态代替业务完成状态。
- 任务完成、跳过或投票提交后，对应项目会从待处理列表自然消失。
- “仅供了解”保留近期提醒和成员自己的通知历史，未读消息支持逐条或全部标记已读。
- 所有入口使用现有家庭范围 API，跨家庭数据不会进入聚合结果。
- 管理员仍可访问原有站内消息、外部渠道和投递记录，不向普通成员暴露渠道管理功能。

## 快捷新增

- 普通成员首页提供不小于 44 x 44 像素的快捷新增按钮。
- 弹层复用 `AdaptiveDialog`，手机和窄屏 Web 支持鼠标或触控拖动、跟手位移、下拉关闭及关闭按钮；Web 使用 Pointer Event，原生使用 `PanResponder`。
- 任务、提醒和投票使用 `create=1` 深链打开既有表单；购物项滚动到既有手动添加区域；点菜进入既有点菜页。
- 深链表单关闭后清理 `create` 参数，可再次从首页打开，不依赖回车、Escape 或其他快捷键。
- 新增操作继续复用原业务接口、权限校验、加载状态和错误反馈。

## 自动验收

- Mobile TypeScript 与 Expo lint 无错误或警告。
- Expo Web export 成功，生产静态包不包含新增运行时错误。
- Playwright 覆盖 375 像素小屏、标准移动视口、横屏、无触控窄屏鼠标和宽屏布局。
- 浏览器回归检查首页默认折叠与点击展开、收件箱、快捷新增、`create=1` 表单、鼠标/触控拖动跟手、释放关闭、44 像素触控目标和无横向溢出。
- 全量 API 回归和结构漂移继续通过，确认本批没有改变数据库契约。

## 数据与权限边界

- 首页和收件箱不复制任务、投票、提醒、通知或活动数据。
- 普通成员只能看到现有 API 根据 JWT 家庭和成员身份返回的数据。
- 快捷新增只负责导航到现有业务表单，不绕过服务端权限、幂等或事务约束。
- 本批不读取、修改或输出账号密码、Hermes 密钥、Plex Token 或 MoviePilot API Key。
