# M7-A1 家庭知识库验收

## 交付范围

家庭知识库保存家庭流程、设备说明、常用联系、居家资料和其他非敏感文本。页面支持搜索、分类、置顶、创建、编辑、归档、恢复、查看版本历史和还原历史版本，所有操作均可通过鼠标或触控完成。

本批不上传知识库附件，不保存身份证件、健康资料、账号密码、Wi-Fi 密码或连接器密钥。参考链接只允许 HTTP(S)，正文不会复制到家庭活动审计或服务日志。

## 数据与权限

- `knowledge_articles` 保存文章当前版本、分类、摘要、正文、参考链接、标签、置顶、版本号、创建者、更新者和归档状态。
- `knowledge_article_revisions` 保存每次创建、编辑、归档、恢复和历史还原后的完整快照；数据库触发器拒绝更新和删除历史行。
- 所有表都包含家庭范围，跨家庭详情、编辑和历史查询统一返回 `404`。
- 所有活动家庭成员可阅读和创建文章；创建者可编辑、归档、恢复和还原自己的文章；`owner/admin` 可维护全部文章并设置置顶。
- 归档会明确取消置顶；恢复不会自动重新置顶。历史还原生成新版本，不覆盖或删除当前历史。

## 幂等与并发

每个写操作包含家庭级幂等键，版本快照保存请求 SHA-256 指纹。相同键和相同载荷重试返回原结果，不增加版本；同一键复用于不同载荷返回 `409`。

编辑、归档、恢复和历史还原都提交 `expectedVersion`。事务先锁定文章行再比较版本，因此两个基于同一旧版本的并发操作只有一个成功，另一个返回当前版本冲突，不会静默覆盖家庭成员的修改。

## API

| 接口 | 行为 |
| --- | --- |
| `GET /knowledge-articles` | 按状态、分类、关键词或标签读取家庭文章 |
| `GET /knowledge-articles/:id` | 读取家庭内文章详情和当前操作权限 |
| `GET /knowledge-articles/:id/revisions` | 读取倒序版本历史，不返回幂等键或请求指纹 |
| `POST /knowledge-articles` | 幂等创建文章 |
| `PATCH /knowledge-articles/:id` | 使用预期版本编辑正文、标签或管理员置顶状态 |
| `POST /knowledge-articles/:id/archive` | 显式归档并生成版本快照 |
| `POST /knowledge-articles/:id/restore` | 显式恢复并生成版本快照 |
| `POST /knowledge-articles/:id/revisions/:version/restore` | 将旧内容复制为新的当前版本 |

## 前端

- 首页增加独立“家庭知识库”模块，桌面侧栏增加固定入口，移动底栏仍保持原有高频入口数量。
- 列表支持使用中/已归档分段筛选、分类筛选和按钮触发搜索。
- 文章详情、版本历史、编辑表单和确认操作使用可点击控件，不依赖键盘快捷键或悬停。
- 管理员置顶使用开关；归档、恢复和历史还原使用明确确认框；成功后立即刷新文章与版本历史。
