# M5-A 访客与来访计划验收

## 已交付

- 独立的访客档案、来访计划、来访参与人和一次性访客邀请。
- 家庭管理员可维护访客、安排来访、结束或取消来访，并为每位参与访客单独生成邀请。
- 来访聚合到统一日历，首页和桌面导航提供独立入口。
- 访客打开链接无需家庭账号，只能读取自己的称呼、家庭名称、该次来访的主题、时间和面向访客的备注，并可确认参加或婉拒。
- 访客回执通知接待成员；家庭活动记录来访与邀请操作。

## 数据与权限边界

- `guests` 不关联 `accounts` 或 `members`，不能登录、不能获得家庭角色、不能映射 Plex/Emby 用户。
- `visits` 通过 `visit_guests` 支持一次来访的多位访客；来访数据始终属于一个家庭。
- `guest_invitations` 只保存 SHA-256 令牌摘要。随机令牌只在创建响应中返回一次，撤销、到期或来访取消后不可使用。
- 访客目录与来访管理需要 `manage_guests`，仅 owner/admin 具备。普通家庭成员不能读取或写入该模块。
- 公共接口不返回家庭成员、库存、片单、家庭活动、网络配置、凭据、令牌摘要或内部 ID。

## API

```text
GET/POST/PATCH  /guests
GET/POST/PATCH /visits
POST           /visits/:id/invitations
DELETE         /guest-invitations/:id
GET            /guest-invitations/:token             (公开)
POST           /guest-invitations/:token/response    (公开)
```

公开响应只接受 `{ "attending": true | false }`，令牌始终位于 URL 路径而不放进请求正文。

## 自动验收

- 全量 API 回归从空库应用迁移，检查实体无结构漂移。
- 验收脚本覆盖普通成员拒绝访问、时间范围校验、家庭日历聚合、明文令牌一次性返回、公共最小响应、访客确认、家庭侧回执和撤销失效。
- 移动端 TypeScript 检查覆盖家庭端和公开访客路由。

## 后续边界

- 本批不让访客直接写入点菜或投票，避免在没有独立反滥用、撤销和审计模型前把匿名链接扩大为家庭数据写权限。
- 访客 Wi-Fi 二维码、中兴设备只读接入、临时网络权限和到期清理属于后续 M5 批次。
