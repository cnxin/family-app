# M7-A3 家庭回忆与今日家庭助理验收

## 交付范围

家庭回忆保存标题、回忆日期、类别、非敏感故事、标签、可选家庭事项来源和私有照片。页面提供时间线、搜索、分类、创建、编辑、归档、恢复和照片追加，全部核心操作都可通过鼠标或触控完成。

普通成员首页升级为“今日家庭助理”：继续展示今日菜单、任务、提醒和采购，并增加本周待办、待来访、30 天内维护、计划中行程和最近家庭回忆。助理只聚合已有模块事实，不建立第二份状态，也不代表用户自动完成、扣库或确认任何业务操作。

本批不做人脸识别、人物自动标记、精确定位、公开分享或自动生成内容，不保存身份证件、健康资料、支付信息、账号密码或连接器密钥。照片说明和故事不会复制到家庭活动审计或服务日志。

## 数据与权限

- `family_memories` 保存家庭、标题、日期、类别、故事、标签、可选来源、版本、创建者、更新者和归档状态。
- `family_memory_photos` 保存家庭、回忆、私有存储键、MIME、大小、说明、创建者和上传幂等信息。每条回忆最多 6 张，每张不超过 10MB，只接受 GIF、JPEG、PNG 和 WebP。
- `family_memory_operations` 保存创建、编辑、归档和恢复的家庭、对象、结果版本、操作者、幂等键、请求指纹和时间；数据库触发器拒绝更新或删除历史行。
- 所有活动家庭成员可读取和创建回忆；创建者可维护自己的回忆，`owner/admin` 可协助维护家庭内全部回忆。
- 所有查询、来源校验、照片上传和状态操作限制 `householdId`；跨家庭对象统一返回 `404`。

## 隐私与照片访问

回忆照片不复用公开上传目录，而是保存在 `uploads/.private/memories/<householdId>/`。列表和详情只返回 10 分钟有效的 HMAC 签名读取地址；读取响应使用 `private, no-store` 和 `nosniff`，不接受客户端提供任意文件路径。

活动流只记录回忆 ID、标题、日期、类别和动作等必要摘要。故事正文、照片说明、存储键、幂等键和请求指纹都不进入活动摘要。完整照片仍属于备份附件范围，需要随数据库一起备份和恢复。

## 幂等与并发

创建、编辑、归档、恢复和照片上传都提交家庭级幂等键与 SHA-256 请求指纹。相同键和相同载荷重试返回原结果；相同键复用于不同载荷返回 `409`。

编辑、归档和恢复提交 `expectedVersion`，事务行锁确保基于同一旧版本的并发请求只有一个成功。归档保留文字、照片和不可变操作历史；恢复使用反向状态操作，不删除历史行。

## API

| 接口 | 行为 |
| --- | --- |
| `GET /memories` | 按状态、类别、关键词、标签、年份和数量读取家庭回忆 |
| `GET /memories/:id` | 读取家庭内回忆详情、签名照片地址和当前操作权限 |
| `POST /memories` | 幂等创建家庭回忆并记录不可变操作 |
| `PATCH /memories/:id` | 使用预期版本编辑回忆 |
| `POST /memories/:id/archive` | 显式归档并保留全部历史 |
| `POST /memories/:id/restore` | 显式恢复已归档回忆 |
| `POST /memories/:id/photos` | 校验权限、类型、大小、数量和幂等键后追加私有照片 |
| `GET /memories/:memoryId/photos/:photoId/content` | 使用短时 HMAC 签名读取私有照片内容 |

## 前端与交互

- 家庭回忆采用移动优先时间线，支持珍藏中/已归档、分类和按钮触发搜索；桌面侧栏提供固定入口，移动底栏保持 5 个高频入口。
- 创建和编辑使用带可见关闭按钮的 `AdaptiveDialog`；紧凑视口支持实时跟手的上下拖动、回弹和下拉关闭，同时保留所有可点击操作。
- 日期使用可点击日历选择器，类别使用 Lucide 图标选项；触控目标至少 44px，不依赖悬停、快捷键或手势完成关键操作。
- 照片先显示本地预览，再由用户明确点击“添加照片”；上传中禁用重复操作并显示进度，成功后刷新详情并显示可关闭反馈。
- 归档和恢复均使用明确确认框。加载、空状态、失败和完成状态都有可见反馈。
- 今日家庭助理复用菜单、任务、提醒、购物、来访、资产、出行和回忆查询，不保存派生计数。
