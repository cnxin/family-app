# M4-J 剧集季入库核验验收

## 目标

- MoviePilot 的整理状态与 Plex/Emby 的实际可播放状态分开呈现。
- 仅当媒体服务器明确返回目标季时，片单才显示该季可播放。
- 媒体服务器返回的集数只表示当前已发现的集数，不作为官方总集数，也不据此声明整季下载完整。

## 查询边界

- `POST /media/library-availability` 仍只接受家庭片单 ID，服务端重新校验家庭范围。
- 服务端只读取每个片单条目当前最新的非取消剧集请求，并只向 Plex/Emby 查询该请求的季号。
- Plex 通过剧集子目录读取季号与 `leafCount`；Emby 通过该剧集的 Seasons 列表读取季号与 `ChildCount`。
- 电影与没有剧集订阅的片单条目不触发额外季查询。
- 匹配缓存键包含家庭、连接器配置版本、外部编号和目标季号，60 秒内避免重复访问 NAS。

## 呈现规则

- MoviePilot 完成但未匹配媒体库：显示“等待媒体库同步第 N 季”。
- 已匹配整部剧但目标季未被服务器确认：显示“已发现剧集条目，等待第 N 季核验”。
- 目标季已确认：显示“第 N 季可播放”，并按 Plex/Emby 分别显示当前已发现集数或“集数待核验”。
- 多个媒体库同时存在时保留全部播放入口与各自季信息；主媒体库只影响排序。

## 安全与数据归属

- Plex/Emby 持有季和集的事实数据，家庭应用不把该数据写成独立家庭主数据。
- 返回内容不包含 Token、API Key、整理路径或文件名。
- 单个媒体库查询失败时保留其他来源结果，不阻断片单、订阅、投票和排期。

## 自动验证

- Plex 契约覆盖目标季子目录与已发现集数。
- Emby 契约覆盖目标季 Seasons 列表与已发现集数。
- API 和 Expo TypeScript 回归覆盖前后端响应契约。
