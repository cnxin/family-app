读图要点
  1. 三层：场景一排（没有就不出现）→ 房间分段 → 设备卡。连接状态收进标题下一行小字，不再占右栏。
  2. 一张卡只有：图标、中文名、一句状态、至多一个主按钮。按钮上的字 = 按下会发生的事（暂停 / 关上 / 打开），不是当前状态。
  3. 状态靠颜色：松绿底 = 开着 / 运行中；平底 = 关着 / 待机；暖橙图标 = 要留意（滤芯低、暂停、出错）；半透明 = 离线。
  4. 点主按钮 = 直接执行（成功给轻触感）；点卡片其他任何地方 = 打开详情 sheet。只读设备（洗衣机、净水）整张卡都是详情入口。
  5. 离线设备排到本房间末尾；「在今天页显示」的设备在这里照常按房间排，不单独置顶。
  6. 成员视角：没开放控制、或 minRole 不够的设备不出主按钮，卡片其余一样。
  7. 空调状态后的「≈」= 红外遥控，只知道上次发了什么（现有 assumed 字段），详情里写全。
