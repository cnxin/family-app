# 移动端统一 UI 方向

## 决策

统一移动端采用方案 A「流动日常」。方案 B「清晰控制」仅保留为本次设计决策的对照材料，不进入移动端主设计体系。

方案 A 的核心方向：

- 首页以家庭今日时间线和生活内容为主，不做管理仪表盘。
- 小管家入口自然融入日常任务，而不是独立的命令控制台。
- 使用克制的半透明导航、柔和层级和即时触控反馈。
- 保留五个底部标签，并覆盖深色模式、reduced motion 和至少 44pt 的触控目标。

## 审查范围

这是独立 HTML/CSS/JavaScript 交互原型，尚未接入 `apps/mobile` 的 React Native 生产页面。审查重点是信息架构、视觉层级、交互反馈和跨页面一致性，不是生产组件实现质量。

原型包含首页、日历、小管家、通知、账户、资产详情、快捷新增和深浅色切换。`comparison.png` 是两套方向的静态对比图，交互页面默认展示两套方案，评审时以方案 A 为准。

本地预览：

```bash
python3 -m http.server 4173 --directory docs/ui-prototypes/mobile-ui-study
```

然后打开 `http://127.0.0.1:4173`。
