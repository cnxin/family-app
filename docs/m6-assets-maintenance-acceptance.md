# M6-A3 家庭资产与维护验收

## 已交付

- 新增独立家庭资产模块，记录名称、分类、位置、品牌、型号、序列号、购买日期、价格、保修到期日和备注。
- 资产支持在用与已归档状态。归档不会删除资料、维护计划或维护历史，恢复后可继续使用。
- 每件资产可保存购买凭证、说明资料、保修材料和其他资料；支持图片上传或 HTTP(S) 链接。
- 每件资产可建立多个维护计划，记录周期天数、下次到期日、启停状态和备注。
- 完成维护必须由用户明确确认，确认页展示执行日期、费用和完成后的下次到期日。
- 维护完成追加不可变历史，保存家庭、资产、计划、执行成员、执行时间、费用、备注、周期前后快照和幂等来源键。
- 启用中的维护计划复用家庭提醒：可以从提醒中心筛选、创建和管理维护提醒，通知跳转回对应资产与计划。

## API 与数据

```text
GET    /assets
GET    /assets/:id
POST   /assets
PATCH  /assets/:id
POST   /assets/:id/documents
DELETE /asset-documents/:id
POST   /assets/:id/maintenance-plans
PATCH  /maintenance-plans/:id
POST   /maintenance-plans/:id/complete
```

- `home_assets` 保存家庭资产主档；分类为家电、家具、数码、工具或其他，状态为在用或已归档。
- `asset_documents` 保存资料类型、标题、地址、创建者与时间。地址仅允许 `/uploads/...` 或 HTTP(S)，不接受脚本等不安全协议。
- `maintenance_plans` 保存周期和下次到期日；同一资产不能建立同名计划。
- `maintenance_records` 保存每次实际执行记录和 `nextDueDateBefore/nextDueDateAfter` 快照。家庭和幂等键组合唯一，数据库触发器拒绝任何 `UPDATE` 或 `DELETE`。
- 迁移历史按序推进到 `1785229500000-add-home-assets`，共 32 个迁移；`synchronize` 继续保持 `false`。

## 业务边界

- 所有列表、详情、资料、计划和维护操作都按 `householdId` 隔离；其他家庭 ID 按不存在处理。
- 购买价格、维护费用不能为负数；保修到期日不能早于购买日期；日期必须是有效的 `YYYY-MM-DD`。
- 已归档资产不能新增或完成维护，停用计划不能完成维护。归档资产或停用计划会取消仍待发送的相关提醒。
- 完成维护以实际执行日加周期天数计算下一次日期。计划级事务锁与家庭幂等键保证重复点击、接口重试和并发请求只生成一条历史。
- 同一幂等键不能用于其他维护计划。完成维护后，旧周期的待发送提醒会以 `source_rescheduled` 原因取消，避免按旧日期误发。
- 删除资料只删除资料引用，不删除已上传文件；维护历史始终保留。资产本批只提供归档，不提供物理删除。

## 前端验收

- 首页提供“家庭资产”入口和未来 30 天维护数量；资产页支持按在用状态与分类筛选。
- 新建和编辑资产、上传或链接资料、添加维护计划、启停计划、归档和恢复均可用鼠标或触控完成。
- 资产详情同时展示购买保修信息、资料、维护计划和历史；到期、临期、已停用及已归档状态清晰可见。
- 完成维护前展示预计的下次到期日；提交后显示成功或重复确认状态，失败信息保留在确认窗口中。
- 维护计划可以直接打开提醒创建页；提醒中心新增“维护”筛选和图标，通知跳转参数会自动打开对应资产。
- 资料删除和资产归档有二次确认；计划启停有明确的加载、成功与失败状态，所有操作均不依赖键盘快捷键。

## 自动验收

- 全新数据库初始化、旧结构升级和实体结构漂移检查包含四张新增表与提醒来源约束。
- API 回归覆盖资产创建、在用/全部筛选、购买保修校验、资料 URL 白名单和重复删除。
- 随机其他家庭资产验证列表不可见、详情返回 404、维护计划写入返回 404。
- 同名维护计划返回 409；启用计划进入统一提醒来源并返回资产详情路径。
- 两个并发完成请求验证只产生一条维护记录、只有一个首次确认结果，并按实际执行日推进周期。
- 维护完成验证旧提醒取消；相同幂等键用于不同计划返回 409；停用计划完成返回 409。
- 数据库直接更新和删除维护记录均被不可变触发器拒绝。
- 全量 TypeScript、lint、Expo Web 导出和浏览器服务可用性作为交付门禁。

## 后续边界

本批不将资产当作库存项，也不自动生成或扣减滤芯等耗材。耗材与库存、购物项的显式关联留给后续独立迁移，不能根据资产名或维护计划名猜测。敏感证件和健康资料在加密、备份与细粒度权限完成前不纳入家庭资料库。
