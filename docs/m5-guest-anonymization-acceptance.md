# M5-D 访客匿名化验收

## 已交付

- 家庭管理员可对不再有已安排来访的访客执行匿名化，并在客户端通过二次确认触发。
- 匿名化会将姓名替换为“已匿名访客”、头像替换为通用标识、清空家庭备注、停用档案并记录匿名化时间。
- 仍有效的访客邀请会立即撤销；带有该访客 ID 的家庭活动摘要会替换为去标识化内容。
- 来访、菜单选择、投票和其他业务历史继续保留匿名事实，避免删除外键数据导致历史记录损坏。

## API

```text
POST /guests/:id/anonymize    (需要 manage_guests)
```

普通成员不能调用该接口。已匿名化档案不能重新编辑或启用，操作重复执行保持幂等。

## 自动验收

- 普通成员匿名化请求返回 403。
- 存在已安排来访时返回 409，避免影响正在协作的邀请和菜单。
- 取消或结束来访后，管理员可匿名化；响应不再包含原姓名、头像或备注，档案被停用。
- 匿名化后不能通过一般编辑接口重新启用该访客。

## 边界

- 本操作是去标识化而非物理删除：为保持家庭业务历史完整，来访、点菜和投票记录仍保留，但不再通过访客档案展示身份资料。
- 家庭成员自行写入的自由文本、截图或外部导出不在自动扫描范围内，应由家庭管理员按实际情况清理。
