# M5-B 手动访客 Wi-Fi 二维码验收

## 已交付

- 家庭管理员可以维护多个手动访客 Wi-Fi 配置，并在一次来访中明确选择一个配置或不提供网络。
- WPA 密码使用现有服务端 AES-256-GCM 凭据保护机制加密保存；管理端列表、活动记录和普通访客响应均不返回密码或密文。
- 有效邀请页只在来访仍处于已安排状态、选定配置仍启用且凭据可解密时显示标准 Wi-Fi QR 载荷。客户端只绘制二维码和 SSID，不显示密码文字。
- 撤销或过期邀请、取消来访、停用配置都会让二维码立即不可见；本批不连接、读取或改动中兴路由器。

## API

```text
GET/POST/PATCH  /guest-wifi-profiles       (需要 manage_guests)
POST/PATCH      /visits                    (guestWifiProfileId 可选)
GET             /guest-invitations/:token  (公开；仅在有效时附带 wifi.qrPayload)
```

`wifi.qrPayload` 是专供二维码渲染的 Wi-Fi 连接载荷，公开响应不包含独立密码字段、配置 ID、密文、家庭成员或路由器信息。访问该载荷等同于得到一次短期访客网络连接权限，因此邀请链接不得公开传播。

## 自动验收

- 普通成员不能读取或维护访客 Wi-Fi 配置。
- WPA 弱密码被拒绝，数据库保存的值为版本化密文且不是明文。
- 管理接口不返回密码或密文；来访只能绑定本家庭的启用配置。
- 有效邀请只获得本次来访的二维码载荷；停用配置后公开页立即不再返回二维码。
- 既有邀请撤销、到期或来访取消后继续返回 404，不会残留 Wi-Fi 数据。

## 后续边界

- 等明确中兴设备型号、硬件版本、固件和设备角色后，再单独评估只读状态接入；任何写入网络的操作必须单独授权、二次确认并记录审计。
- 本批不生成路由器访客网络、不轮换密码、不采集设备 MAC、在线状态或浏览记录。
