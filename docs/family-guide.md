# 小管家 · 家里人用法

**怎么打开**：手机浏览器输入地址，用自己的账号和密码登录。
- 在家（连着家里 Wi-Fi）：【家里地址，King 稍后填】
- 在外面：【外面地址，King 稍后填】

建议登录后「添加到主屏幕」，以后点图标就能进。

**底下四个按钮**

| 按钮 | 是什么 |
| --- | --- |
| 今天 | 打开就看这个：今天三顿吃什么、今天要做的事、要买的东西 |
| 吃饭 | 点一下弹出：点菜 · 厨房 · 购物 |
| 日程 | 点一下弹出：日历 · 任务 · 消息 |
| 家里 | 其他不常用的都在这里，比如菜谱、资产、出行 |

右上角的圆头像是「我的」，改密码、退出登录都在里面。

**点菜**：吃饭 → 点菜。先选日期和早餐 / 午餐 / 晚餐，点菜名把它加进「你的菜单」，想少放辣就写在备注里，最后点「提交菜单」。提交之后做饭的人就能看到。

**认领家务**：今天页的任务分「我的」和「全家」两组。「全家」里没人管的事，点「认领」就归你了，它会挪到「我的」。做完点前面的圆圈打勾。

**勾购物清单**：吃饭 → 购物。买到一样就点它前面的圆圈打勾；缺什么就在下面「添加物品」写上。

**有意见或者用着别扭**：日程 → 任务，在「加一件今天要做的事」里写一句，**开头写「反馈：」**，比如「反馈：字太小看不清」，再点「添加」。不用写得很正式，想到就记。
