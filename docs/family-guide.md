# 小管家 · 家里人用法

**怎么打开**：手机连着家里 Wi-Fi，浏览器输入 **http://192.168.50.148:8088**，用自己的账号登录。
- 试用这两周只能在家里用，出门连不上是正常的。
- 地址是 http 开头，浏览器可能提示「不安全」：在家里 Wi-Fi 里用没关系，照常登录。

**第一次用**：打开 King 发的邀请链接，自己起一个登录名（比如 mama）、设一个密码（至少 8 位），以后就用它登录。早就有账号、但从来没设过密码的，第一次登录会先让你设一个密码，设好才能进去。

建议登录后「添加到主屏幕」，以后点图标就能进。

**底下四个按钮**

| 按钮 | 是什么 |
| --- | --- |
| 今天 | 打开就看这个：今天三顿吃什么、今天要做的事、要买的东西 |
| 吃饭 | 点一下弹出：点菜 · 厨房 · 购物 |
| 日程 | 点一下弹出：日历 · 任务 · 消息 |
| 家里 | 其他不常用的都在这里，比如菜谱、资产、出行 |

今天页右上方的圆头像点进去是「我的」：「账号安全」里有「修改密码」，右上角是「退出登录」。电脑上点左边栏底下的头像，选「个人设置」。

**点菜**：吃饭 → 点菜。先选日期和早餐 / 午餐 / 晚餐，点菜名把它加进「你的菜单」，想少放辣就写在备注里，最后点「提交菜单」。提交之后做饭的人就能看到。

**认领家务**：今天页的任务分「我的」和「全家」两组。「全家」里没人管的事，点「认领」就归你了，它会挪到「我的」。做完点前面的圆圈打勾。

**勾购物清单**：吃饭 → 购物。买到一样就点它前面的圆圈打勾；缺什么就在下面「添加物品」写上。

**家里的设备**：今天页「今天吃什么」下面那几张卡片就是家里的设备。卡片右上角的按钮写着「按下会怎样」（开始、暂停、关上），点它就直接执行；点卡片其他地方会打开这台设备的详情，能细调、能看最近谁按过。按钮灰着或没有按钮，说明现在按不了或者管理员还没开放。

**东西放哪儿**：购物清单里打了勾的东西，点「入库」时有一行「放哪儿」，一层层点「房间 → 柜子 → 层格」，点到哪层都可以「就放在这儿」；没有合适的就在底下新建一个。不填也行。平时想记一下某样东西放哪，点右上角的放大镜（电脑上按 ⌘K），搜「记一下」，先选地方，再选是哪样东西。

**怎么导账单**：家里 → 财务 → 流水，点「导入账单」，选导进哪个账户、账单从哪来（支付宝邮件里的 zip 先解压出 csv；微信在 钱包 → 账单 → 下载账单 里导出），再选文件。预览里每行都能改分类、勾掉不想记的，以前导过的会标「已导入」、不会重复记，点「确认导入」之后才进账本。改过的分类会记住，下次同一家店自动用这个分类。导完觉得分错了，在流水里点那一笔就能改分类、金额、名称，也能删；改完分类会问一句要不要把同一家店的其它几笔一起改。要一次改很多笔，点流水顶上的「选择」，勾上几笔再点「改分类」「改账户」或「删除」。

**放大镜（电脑上按 ⌘K）**：右上角的放大镜能找页面、菜、东西放在哪。不用想该点哪儿，直接说你要干什么就行，比如「记一笔 38 买菜」「牙膏放哪了」。

**搜索会记下你说的话**：在放大镜（⌘K）里输的话会记一条，存在家里这台服务器上，不会发出去，用来让小管家慢慢学会家里人怎么说。想看自己说过什么：家里 → 问问小管家 → 设置 → 原话记录，「清空我的」能全删。管理员在同一处可以关掉「记录原话」。

**有意见或者用着别扭**：直接在家庭微信群里说就行，King 会记下来。也可以在小管家里记：日程 → 任务，在「加一件今天要做的事」里写一句，**开头写「反馈：」**，比如「反馈：字太小看不清」，再点「添加」。不用写得很正式，想到就说。
