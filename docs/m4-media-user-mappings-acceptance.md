# M4 Plex/Emby 用户映射验收

> 完成日期：2026-07-30
> 实施范围：媒体用户目录、家庭成员显式映射、权限与失效记录处理

## 1. 数据与身份边界

- `media_user_mappings` 保存家庭、连接器、媒体服务器 ID、外部用户 ID 与家庭成员的显式关系。
- 同一家庭、连接器和服务器内，一个外部用户只能映射一位成员，一位成员也只能映射一个外部用户。
- Plex/Emby 更换服务器后不复用旧映射；旧记录标记为“已失效”，只允许管理员取消。
- 不按用户名、显示名或邮箱猜测家庭成员。没有显式映射的播放事件后续只做脱敏审计，不归属任何成员。
- 映射只保存外部用户标识和显示名快照，不保存 Plex Token、Emby API Key 或服务地址。

## 2. 外部用户目录

- Plex 使用当前家庭连接器访问 `/accounts`，读取服务器 ID、用户 ID 和显示名。
- Emby 使用当前家庭连接器访问 `/Users`，读取服务器 ID、用户 ID、显示名和停用状态。
- Plex 与 Emby 可以同时启用和独立刷新；单个连接器离线不会阻断另一个目录或家庭核心数据。
- 服务暂时离线时保留映射并标记为“暂不可验证”，不会误报服务器变化或自动解除关联。
- 停用账号保留现有映射供清理，但不能新建或更换关联。

## 3. API 与权限

```text
GET    /media/playback-users
PUT    /media/playback-users/:provider/:externalUserId/mapping
DELETE /media/playback-user-mappings/:mappingId
```

- 三个接口均要求 `manage_integrations` 权限；普通家庭成员不能读取目录、建立或取消映射。
- 写接口校验家庭、连接器、当前服务器、外部用户和目标成员，不能跨家庭引用。
- 重复占用同一成员时返回冲突，不静默覆盖其他外部账号的映射。
- 建立和取消映射均写入家庭活动，保留提供方、外部用户与成员信息，不记录凭据。

## 4. 客户端

- “观影设置 -> 用户映射”展示 Plex/Emby 连接状态、外部账号及当前家庭成员。
- 管理员可通过鼠标或触控刷新目录、选择成员和取消关联，不依赖键盘快捷键。
- 选项使用单选语义并同步选中状态；移动端和桌面 Web 都能被辅助技术识别。
- 当前服务器账号、停用账号、暂不可验证映射和旧服务器失效记录使用不同状态提示，避免误关联。

## 5. 自动验收

- 连接器契约覆盖 Plex/Emby 用户目录、服务器 ID、停用状态及请求头凭据。
- API 回归覆盖权限、家庭隔离、重复成员冲突、服务器变化、建立映射、取消映射和活动记录。
- PostgreSQL 空库、旧结构升级和完整业务回归验证迁移可重复应用。
- Playwright 在 390x844 与 1440x900 视口验证读取、映射、取消、失效状态和横向溢出。
- API 构建与完整 API 回归、移动端 TypeScript、Expo Lint 和 `git diff --check` 必须通过。

## 6. 后续边界

本批只建立可靠的身份映射，不保存观看会话或播放进度。下一批接入 Plex/Emby 播放开始、停止和进度事件；只有当前服务器上有效且已映射的用户才能归属家庭成员，未映射事件继续保留为脱敏审计。
